## Store Listing Assets

### App Icon Requirements
- **Size:** 512 x 512 px
- **Format:** 32-bit PNG with alpha
- **Design:** Should feature the NutriChef logo/branding
- **Colors:** Use the app's primary colors (Green #4CAF50, Orange #FF7043)
- **No text:** App name should not be in the icon itself

### Feature Graphic
- **Size:** 1024 x 500 px
- **Format:** PNG or JPEG
- **Content:** Showcase the app's main features or value proposition
- **Text:** Keep minimal, focus on visual appeal
- **Branding:** Include app name and tagline

### Screenshots

#### Phone Screenshots (Required - minimum 2, maximum 8)
- **Dimensions:** Min 320px, max 3840px on any side
- **Aspect ratio:** 16:9 or 9:16 recommended
- **Recommended size:** 1080 x 1920 px (portrait)

**Suggested Screenshots:**
1. **Dashboard/Home Screen** - Show the main interface with key features highlighted
2. **Inventory Management** - Display the ingredient list with photos
3. **Photo Upload** - Show the AI detection feature in action
4. **Recipe Recommendations** - Display personalized recipe cards
5. **Recipe Detail** - Show a complete recipe with ingredients and steps
6. **Meal Planning Calendar** - Display the weekly meal plan view
7. **Nutrition Tracking** - Show charts and nutritional data
8. **Profile/Settings** - Display user profile and customization options

**Screenshot Tips:**
- Use actual app content, not mockups
- Include annotations or captions to explain features
- Show the app in use with realistic data
- Ensure high contrast and readability
- Use consistent device frames (optional)

#### Tablet Screenshots (Recommended)
- **7-inch:** 1024 x 600 px or 600 x 1024 px
- **10-inch:** 1920 x 1200 px or 1200 x 1920 px
- Minimum 2 screenshots per tablet size

### Promo Video (Optional but Recommended)
- **Duration:** 30 seconds to 2 minutes
- **Format:** YouTube link
- **Content:** 
  - App overview and key features
  - Show actual app usage
  - Include voiceover or captions
  - End with download CTA

## Privacy Policy

A privacy policy is **required** for Play Store submission. It must be hosted on a publicly accessible URL and cover:

### Required Sections
1. **What data is collected:**
   - User account information (name, email)
   - Inventory items and photos
   - Recipe preferences and history
   - Meal plans and nutrition data
   - Device information (for analytics)

2. **How data is used:**
   - Provide personalized recommendations
   - Improve app functionality
   - Analytics and performance monitoring
   - Customer support

3. **Data sharing:**
   - With whom data is shared (if any)
   - Third-party services used (AI APIs, analytics)
   - Legal requirements

4. **User rights:**
   - How to access personal data
   - How to delete account and data
   - How to opt-out of data collection
   - Contact information for privacy concerns

5. **Data security:**
   - How data is protected
   - Encryption methods
   - Data retention policies

6. **Cookies and tracking:**
   - Use of cookies (if applicable)
   - Analytics tracking
   - How to manage preferences

7. **Changes to policy:**
   - How users will be notified of updates
